ココフォリアログ編集ツール（CClog）取扱説明書

最終更新: 2026-09-29

  • ココフォリアのセッションログ(HTML書き出し)をiPhone/iPadなどのブラウザ上で並べ替え・削除・追加編集し、Notion取り込み用のMarkdown(またはテキスト)に変換できる
  • 読み込んだログの内容はすべて端末内で処理される。どこかのサーバーに送信されることはない

基本の流れ

  • ①ココフォリアのセッションからHTMLを書き出す
  • ②このツールを開き「ファイルを選ぶ」でそのHTMLを読み込む
  • ③発言を確認しながら必要に応じて並べ替え・削除・追加編集
  • ④編集が終わったらサイドバーの「書き出す」からMarkdown・テキスト・プレビュー用HTMLのいずれかをコピー(プレビュー用HTMLはダウンロードのみ)してNotionなどに取り込む
  • 途中で中断しても、編集内容は自動保存されるので次回そのまま再開できる(下記＜自動保存と再開＞参照)
  • 長期保管したいときや、別の端末で続きをやりたいときは「一時保存(HTML)」でこのツール専用の保存ファイルを作っておける(下記＜一時保存＞参照)

ログを読み込む

  • 画面上部の「ファイルを選ぶ」から次のいずれかを選ぶ
    • ココフォリアがセッション画面から書き出したHTML
    • このツールで「一時保存」して作ったHTML(続きの編集用)
  • ココフォリアの書き出しHTMLには、新しい形式(アイコン画像入り)と以前の形式がある。新しい形式・以前の形式のどちらのログも、自動で判別して読み込める(どちらかを選ぶ操作は不要)
    • 新しい形式のログには、キャラクターの表情差分画像(アイコン)が含まれている。読み込むと画像も一緒に取り込まれ、発言ごとにアイコンが表示される(下記＜発言の表示のされ方＞参照)
    • 以前の形式のログには画像が含まれていないため、アイコンは表示されない(あとから「発言者を管理する」で画像を追加することはできる)
  • 読み込みが終わると発言が一覧に並ぶ。読み込みパネルは自動で折りたたまれ、代わりに読み込み中のファイル名と発言件数が表示される。別のファイルに読み込み直したいときは「変更する」ボタンから選び直せる
  • ログ以外のHTMLを選んでしまった場合は「発言を読み取れませんでした」という案内が表示され、読み込みパネルは畳まれずそのまま残る。ファイルを選び直す

自動保存と再開

  • 編集するたびに、内容がブラウザ内に自動保存される(端末の外には出ない)。次にツールを開くと読み込み画面に「編集途中の内容が残っています」という一覧が出て、「再開」を押せば続きから編集できる
  • シナリオごとに枠が分かれており、最新5件まで残る。別のシナリオのログを読み込んでも、前のシナリオの編集内容は消えない
    • 同じシナリオを編集し直した場合は同じ枠が上書きされるので、件数は増えない
    • 6件目を読み込むと、一番古いものだけが自動的に押し出される
  • 読み込み後にパネルが畳まれても、「変更する」を押せば一覧が再表示され、そこから別のシナリオへ切り替えられる。いま開いているログは一覧には出ない
  • いらなくなった記録は各行の「破棄」で消せる(確認ダイアログあり)
  • 注意: これは作業中断の保険であって、保管場所ではない
    • iPhone・iPadのSafariは、7日間サイトを開かないと自動保存を消す仕様がある
    • 保存できる容量にも上限があり(iPhoneでおよそ5MB)、大きなログを何本も抱えると古いものから自動的に手放される。表情差分画像を含むログは、画像のぶんだけ容量が大きくなる
    • 長期保管したいときは「一時保存(HTML)」でファイルとして書き出しておく

発言の表示のされ方

  • 発言カードには、通し番号・タブ名・(ダイスロールなら)「🎲 ダイスロール」の印が表示され、左端が発言者の色で縁取られる
  • 発言者ごとに、表示方法が次の2種類に分かれる(サイドバーの「発言者を管理する」で切り替え可能)
    • キャラクター発言: 表情差分画像(アイコン)から吹き出しが出る表示。アイコンは発言者の色で縁取られる
    • 地の文: アイコンを使わない、従来どおりの「発言者：本文」の表示
  • 読み込んだ直後は、ログの中で一度でも画像付きで発言している発言者は「キャラクター発言」、一度も画像を使っていない発言者(KPなど)は「地の文」に自動で振り分けられる
  • ダイスロールの発言は、キャラクター発言の発言者であっても吹き出しにせず、常に地の文と同じ見た目で表示される(一覧・プレビュー用HTMLとも共通)
  • ココフォリアのシステムメッセージ(SAN値の変化通知など、発言者のいないもの)は、発言者名のない専用の見た目で表示される

発言の編集

  • 発言カードを1回タップ(クリック)すると選択され、画面下部に操作バーが出る。もう一度タップすると選択解除
    • 操作バーのボタン:「↑上へ／↓下へ」(選択中の発言を1つ上下に移動)、「編集」(内容を編集)、「削除」(確認ダイアログあり)、「＋この下に発言を追加」(すぐ下に新しい発言を挿入)
    • 操作バー右上の「▾」で操作ボタンだけ折りたたみ可能(ファイル名や選択中の表示は残る)。「×」で選択解除
  • 発言カードを素早く2回タップ(ダブルクリック)すると、選択操作を挟まずそのまま編集画面が開く。保存・キャンセルは通常の編集画面と同じ
  • 「編集」「＋この下に発言を追加」で開く画面で設定できるもの
    • タブ: ココフォリアの発言タブ(例:[main])。既存から選ぶか「＋新しいタブを追加する」で新規作成
    • 発言者: 既存から選ぶか「＋新しい発言者を登録する」で新規登録(新規登録時は色も設定)
    • 本文: 発言のテキスト
    • ダイスロールとして扱う: チェックすると書き出し時にダイスロールとして扱われ、絞り込み・成功失敗判定の対象になる。新規追加時は本文の内容から自動でオン/オフが切り替わるが手動でも変更可
    • 発言者の色: あらかじめ用意された色見本(スウォッチ)から選ぶか、「カラーコード」欄に#03a9f4のような16進数を直接入力
    • 表情差分(アイコン): 選んだ発言者が「キャラクター発言」のときだけ表示される欄。その発言者が持っている表情の中から、この発言に使う画像を選ぶ(「画像なし」も選べる)。「＋ 新しい画像を追加」で端末内の画像を読み込み、その発言者の表情として追加したうえでこの発言に使うこともできる
  • サイドバーの「本文が空の発言をまとめて削除」で、ココフォリアのシステムメッセージなど本文が空の発言をまとめて削除できる(実行前に件数確認ダイアログあり)

発言者を管理する(色・表示方法・画像)

  • サイドバーの「発言者を管理する(色・表示方法・画像)」を押すと、ログに登場する発言者の一覧が開く。発言者ごとに次の3つをまとめて設定できる(以前の「発言者の色を管理する」から名前が変わり、機能が増えた)
  • 色: 「色を変更」を押すと色見本とカラーコード欄が出る。色を変えると、その発言者のすべての発言の色が一括で変わる
  • 表示方法: 「🗨️ キャラクター発言」「地の文」のボタンで切り替える(違いは上記＜発言の表示のされ方＞参照)
  • 表情差分画像: 表示方法によって、画像まわりの表示が変わる
    • キャラクター発言の場合: その発言者が持っている表情の一覧が並ぶ
      • サムネイルをタップすると拡大表示される。元の画像は小さいため、拡大するとぼやけて見える
      • サムネイル横の欄で表情に名前を付けられる(初期状態は「表情1」「表情2」…)。発言編集画面で表情を選ぶときの目印になる
      • 「差し替える」で、その表情の画像を別の画像に置き換えられる。その表情を使っているすべての発言の画像が一緒に変わるので、よりきれいな画像に差し替えたいときに使う
      • 「＋ 新しい表情を追加」で表情を増やせる(追加しただけでは既存の発言には割り当てられない。使いたい発言の編集画面で選ぶ)
    • 地の文で、画像を1枚も持っていない場合(以前の形式のログや、KPなど): 「＋ 画像を追加する」で最初の画像を追加できる。追加すると、その発言者のすべての発言に同じ画像が付き、自動的に「キャラクター発言」に切り替わる
    • 地の文だが画像を持っている場合: 「画像 ○件を保持しています」という案内だけが出る。「キャラクター発言」に切り替えると画像が表示される(地の文にしても画像は消えない)
  • 画像は一時保存(HTML)・ブラウザ内の自動保存のどちらにも一緒に保存される

一時保存(ファイルとして書き出す)

  • 「一時保存(HTML)」を押すと、現在の編集内容を保存した専用のHTMLファイルが書き出される
  • 見た目はふつうのログHTMLだが内部に編集データが埋め込まれており、再度「ファイルを選ぶ」で読み込むと続きから編集を再開できる
  • PC(Chrome・Edge)では、初回だけ保存場所を選ぶダイアログが出て、2回目以降は同じファイルに上書きされる(Wordの保存に近い動作)。ファイルが増えていかない。別のログを読み込むと保存先はリセットされ、次の保存でまた選び直しになる
  • iPhone・iPadでは上書きできず、保存のたびに新しいファイルが作られる。ファイル名は「元のファイル名_日時.html」の形式で自動的に付く(例:蝶と熱病[all]_20260729_1530.html)ので、必要に応じて古いものを整理する
  • 「共有して保存(保存先を選ぶ)」ボタン(iPhone・iPadでのみ表示)を使うと、共有シートが開いて保存先を選べる。iCloud Driveの決まったフォルダに置きたいときなどに使う
    • こちらも上書きはできない。iOSは同じ名前のファイルがあっても「置き換えますか?」とは聞かず、別名で保存する仕様のため(実機で確認済み)。ファイル名は「一時保存」と同じ日時つきなので、どれがいつの保存かは名前で見分けられる
  • 日常的な中断・再開は上記の＜自動保存と再開＞で済むので、ファイルの書き出しは区切りがついたときや長期保管したいときだけでよい

絞り込み表示

  • サイドバーの「絞り込み」から一覧に表示する発言を絞り込める(2条件は同時に組み合わせ可)
    • 発言者で絞り込む: 特定の発言者の発言だけ表示
    • 表示するダイスロール判定: ダイスロールのみ／成功系のみ(クリティカル・イクストリーム成功・ハード成功・レギュラー成功・成功)／失敗系のみ(失敗・ファンブル)／ダイスロール以外(会話のみ)
  • サイドバーには現在の絞り込み状態が表示され、絞り込み中はハンバーガーメニューのアイコンにも印が付く
  • 絞り込み中は並べ替え・発言の追加ができない(隠れている発言との位置関係が分かりにくくなるため)。編集・削除は絞り込み中でも可能。「すべて表示」に戻すと並べ替え・追加ができるようになる
  • ダイスロールの自動判定: 本文に「数字+D+数字」(例:1D100)と「＞」が含まれると自動的にダイスロールとして扱われる。成功・失敗判定は本文の末尾(最後の「＞」より後ろ)がココフォリアのCoCダイスボット出力語句(クリティカル・イクストリーム成功・ハード成功・レギュラー成功・成功・失敗・ファンブル)と一致するかで判定。それ以外の判定語句(他システムのダイスボット等)は「ダイスロールのみ」には表示されるが成功系・失敗系の絞り込みには含まれない

書き出し

  • サイドバーの「書き出す」から編集済みのログをMarkdown・テキスト・プレビュー用HTMLのいずれかで出力
    • Markdown(Notion向け): タブごとに見出し(###)で区切られ、発言者名が太字になる。Notionにそのまま貼り付けて使う想定の書式
    • テキスト(.txt): 見出しや太字の記号を使わないシンプルな書式
    • プレビュー用HTML(Notion貼り付け用): NotionのHTMLブロックに貼り付けて「読む」ための、閲覧専用の書式。文字サイズ・フォントは本ツールの画面表示に合わせてある。「発言者：セリフ」を1行にまとめたシンプルな表示で、KP・PLは左に色付きの線で見分けられる(個々のキャラクターは発言者ごとの登録色で表示)。タブ名によって表示が変わる: タブ名が「info」の発言は発言者名を表示せず、地の文よりインデントを下げた引用ブロックとして表示。タブ名が「other」の発言は全体をグレー表示にする(KP・PLの色線も付かない)。それ以外のタブ名(「main」を含む)は通常表示。以前の形式のログは既定のタブ名が「[main]」「[info]」「[other]」のように角括弧付きになっているが、括弧の有無・大文字小文字・全角半角の違いはすべて区別せず同じものとして扱う。新しい形式のログはタブ名が「[メイン]」「[情報]」のように日本語で表示されるが、ログ内部のタブの区別をもとに自動で判定するので、同じように info・other の表示になる。「キャラクター発言」に設定した発言者は、ツール内の一覧と同じくアイコン(発言者の色で縁取り)＋吹き出しで表示される(ただしダイスロールと info タブの発言は吹き出しにならない)。本ツールへの読み込みには使えない(一時保存とは別物の、一方向の書き出し専用フォーマット)。プレビュー用HTMLは閲覧・貼り付け専用のため「コピー」ボタンは表示されず、「ダウンロード」のみ使える
  • 「KP/PL表示を設定」ボタン(書き出す欄に常に表示)から、実際の発言者一覧の中でKP・PLとして扱いたい発言者を(それぞれ複数)選べる。ここで選んだ内容はMarkdown・テキスト・プレビュー用HTMLのすべての書き出し形式に反映される。何も選ばなければ、これまで通り発言者名が「KP」「PL」のものがそのまま対象になる。1人の発言者をKPとPLの両方に設定することはできない(片方を選ぶともう片方は自動的に外れる)
  • 「コピー」でクリップボードにコピー、「ダウンロード」でファイルとして保存(プレビュー用HTMLはダウンロードのみ)。書き出される内容は現在編集中の発言の並び・内容がそのまま反映される(絞り込み表示中でも、絞り込みに関係なく全発言が書き出される)
  • 発言者名の色について: Markdown・テキストはどちらも文字に色を付けられないため、代わりに発言者の色に最も近い丸絵文字(🔴🟠🟡🟢🔵🟣🟤⚫⚪の9色)を発言の先頭に付けて見分けやすくしている。ただし「KP/PL表示を設定」でKPまたはPLとして選んだ発言者には丸絵文字を付けない(進行役・プレイヤー役という性質上、個人を色分けする対象ではないため)
  • Notionへの貼り付け方について: Notionのインポート方法によっては、貼り付けたHTMLの見た目(色・レイアウト)が保持されない場合がある。うまく反映されない場合は、ダウンロードしたHTMLファイルをブラウザで直接開いて読む、またはNotionの貼り付け方法(テキストとして貼り付け／埋め込みなど)を変えて試してほしい

対応環境・注意点

  • 対応ブラウザ: iPhone・iPadのSafari、およびPC・Androidの一般的なブラウザ
  • 画面幅900px以上(PCやiPadの横向きなど)ではサイドバーが常時表示される2カラムレイアウト。それ未満は右上のハンバーガーメニューからサイドバーを開く形式
  • 通信は発生しない: 読み込んだログの内容は端末内でのみ処理され、外部のサーバーに送信されることはない
  • ダークモード: 端末の設定がダークモードの場合、自動的に配色が切り替わる
  • ホーム画面に追加したアイコンについて: iPhone・iPadでホーム画面に追加している場合、ツールのアイコン画像を更新しても、すでに追加済みのショートカットには反映されない(iOSは追加した時点の画像を保存する仕様のため)。新しいアイコンにしたい場合は一度ホーム画面から削除し、追加し直す

うまくいかないときは

  • ファイルを選んでも発言が表示されない → ココフォリアの書き出しHTML、またはこのツールで一時保存したHTML以外を選んでいないか確認。「発言を読み取れませんでした」という案内が出る
  • 「コピー」を押しても反応がない・失敗する → ブラウザやOSの制限でクリップボードへの書き込みができない場合がある。「ダウンロード」でファイルとして保存し、そちらを利用する
  • 並べ替え・発言の追加ボタンが押せない → 絞り込み表示中は操作できない。「すべて表示」に戻す
  • 発言を編集したのに一覧から消えた → 発言者や絞り込み条件を変更したことで絞り込みの対象外になった可能性。「絞り込み」を「すべて表示」に戻すと確認できる
  • 元のログファイルに戻したい → 編集中の内容を保存していない場合、そのままではやり直せない。編集前の元のHTMLファイルを再度読み込む
  • 「編集途中の内容が残っています」が出ない → しばらくツールを開いていないと、ブラウザ側で自動保存が消される(iPhone・iPadは7日間)。また、プライベートブラウズでは自動保存が働かない
  • 誤って違うファイルを読み込んでしまった → 自動保存は消えないので、「編集途中の内容が残っています」から元の続きを再開できる
  • アイコンが表示されない・吹き出しにならない → 「発言者を管理する」でその発言者が「地の文」になっていないか確認する。以前の形式のログには画像が含まれないので、「＋ 画像を追加する」で追加する。ダイスロールの発言は仕様上、吹き出しにならない
  • 発言編集画面に「表情差分(アイコン)」の欄が出ない → 発言者が「キャラクター発言」に設定されているときだけ表示される
  • 拡大した画像がぼやける → 元の画像が小さいため。「発言者を管理する」の「差し替える」で、より解像度の高い画像に置き換える
  • ツールを更新したはずなのに古い画面のまま → ブラウザが古いファイルを覚えている可能性がある。ページを再読み込みする(iPhone・iPadのSafariでは、一度タブを閉じて開き直す)
